How to Play

  • 4 rounds — lightning steal, correct & steal, secret identity, vault code.
  • Teacher controls everything — reveal answers, award points, start timers.
  • Keyboard shortcuts: Space = timer · A = reveal · N = next · U = undo · 1–4 = award point
  • Scores save automatically. Refreshing the page restores progress.
  • Twist cards appear between rounds — click to reveal, then confirm.
  • Shields block one steal. Wagers in Round 3 can gain or lose points.
