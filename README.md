# Operación SER: Abre la bóveda

A single-page classroom game for **Spanish 1** — practice the present tense of **ser** with four competing teams.

**Play:** [https://digaocoite.github.io/operacion-ser/](https://digaocoite.github.io/operacion-ser/)

## Features

- 4 rounds (~20–25 min): Robo relámpago, Corrige y roba, Identidad secreta, El código de la bóveda
- Sticky score bar with team colors, shields, wagers, and point animations
- Teacher-controlled timers, scoring, twist cards, and undo
- Saves progress in `localStorage` — refresh-safe
- Works offline after first load; no login or server required

## Teacher shortcuts

| Key | Action |
|-----|--------|
| Space | Start / pause timer |
| A | Reveal answer |
| N | Next question |
| U | Undo last score |
| 1–4 | Award +1 (Round 1, after reveal) |

## Reset

Use **New Game** in the teacher panel (bottom-right) to clear saved state.
